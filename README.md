# Nifty 50 Portfolio Optimization Using CAPM & Sharpe Ratio

## Project Overview
This project analyses 50 companies listed in the Nifty 50 index to evaluate their risk and return characteristics and identify suitable stocks for portfolio construction.

The study applies the Capital Asset Pricing Model (CAPM), regression analysis and Sharpe Ratio to assess stock performance, systematic risk and risk-adjusted returns.

## Project Objectives
- To identify high-performing Nifty 50 companies by analysing returns and risk using CAPM.
- To evaluate the risk-adjusted performance of stocks using the Sharpe Ratio.
- To construct an optimum portfolio through systematic scoring and stock selection.

## Dataset Overview
- **Sample:** 50 Nifty 50 companies
- **Study Period:** 1 April 2022 – 31 March 2025
- **Data Frequency:** Daily stock closing prices
- **Data Type:** Secondary, quantitative and time-series data
- **Sources:** NSE India, Yahoo Finance and Moneycontrol

## Tools & Techniques
- Microsoft Excel
- Excel Regression Analysis
- Capital Asset Pricing Model (CAPM)
- Sharpe Ratio
- Descriptive Statistics
- Excel Solver
- Portfolio Construction

## Analysis Performed
1. Descriptive Statistical Analysis
2. Daily and Annual Return Calculation
3. Regression Analysis (Alpha and Beta)
4. CAPM Expected Return Calculation
5. Hypothesis Testing
6. Sharpe Ratio and Risk Analysis
7. Stock Filtering and Scoring
8. Portfolio Construction

## Portfolio Construction

The final portfolio consists of five selected companies, each assigned an equal weight of 20%.

| Company | Portfolio Weight |

## Project Outcome
The study evaluates the relationship between risk and return across Nifty 50 companies and demonstrates how CAPM and Sharpe Ratio can support systematic stock selection and portfolio construction.

## Limitations
- The study is limited to 50 Nifty 50 companies.
- The analysis uses historical stock-price data from the selected study period.
- Qualitative factors such as management efficiency and market sentiment are excluded.
- Portfolio selection is based on the models and techniques used in this study.
